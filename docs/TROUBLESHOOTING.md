# 故障排查

## 能配对，没有普通按键

先确认是支持的 Chromecast/G9N9N 样机，以及只连接一支目标遥控器。打开本应用的按键检测模式和按键接收，查看计数。只配对成功不代表接收助手已启动。

普通单键短报告可能被 IOHID 丢弃。不要用方向＋返回组合能触发，就宣称单键或松开正常；需分别验证。

## 等待管理员授权 / 无法开启

确认 Apple PacketLogger 已单独安装；应用中的“选择工具…”应选择完整 PacketLogger.app。助手会拒绝未通过 Apple 验签的文件。

授权只在 macOS 的系统窗口输入，不要把密码写进命令、配置或 Issue。取消授权不会启动接收。工具与系统升级后可能需要重新验证诊断接口。

## 权限开关打开，应用仍未授权

临时签名变化可能让旧记录失效。退出本应用，在系统设置的辅助功能/输入监控中移除旧记录或刷新开关，再打开当前安装路径的应用并重新授权。输入监控可能要求“退出并重新打开”。固定签名身份可减少后续构建的身份变化。

只针对本应用处理权限，不要清空其他软件的权限，也不要全局关闭系统安全保护。

## 按键已登记，但没有动作

关闭“按键检测模式”，确认辅助功能已授权且没有处于“录制”状态。查看当前映射，而不只看“已收到”计数。

“录制”是录制目标 Mac 键盘快捷键。点某一行录制后，在 Mac 键盘上按目标键，不是再按一次遥控器。

返回默认 Backspace（Mac 显示 Delete），适合删除字符；浏览器上一页可另录制 `⌘[`。不同应用对 Home、功能键或组合键的定义不同。

## 麦克风有连接，没有文字

分层检查：语音按下/松开 → BlackHole 有音频 → 外部输入工具选中 BlackHole → 模型与触发方式 → 文字交付。应用本身不执行语音识别。

若只能录到噪音、长会话断流或唤醒后无声，请报告型号、固件、macOS、工具版本及不含个人内容的错误状态。不要将“握手完成”当作音质已验证。

## 停止和恢复

先点击“停止并恢复设置”，等待状态完成后再退出或升级。正常退出或父进程结束会清理；管理员助手本身被强杀时，恢复记录会保留，下次开启先尝试恢复。若提示恢复失败，请保留报错并停止重复启动，不要手工删除恢复记录。

恢复记录及锁位于 `/private/tmp/com.miremote.mapper.capture/`，此兼容命名让本扩展与原应用共享日志资源锁，避免互相覆盖设置。不保存全机原始日志的承诺指本应用的文件输出；系统自身诊断日志仍由 macOS 管理。

## 构建签名提示 resource fork / Finder information

若仓库放在 iCloud、网盘或 File Provider 同步的“文稿”目录，系统可能在清理后重新附加 FinderInfo，导致 codesign 失败。把源码移到普通本地目录（例如 `~/google-remote-voice-mac`），再运行 `./build.sh`；不要通过关闭系统安全机制绕过。

## 杂音、断续、重复识别

松开语音键后查看日志的“语音接收统计”：在已测试160字节帧的样机上，较长语音应接近50包/秒。约32包/秒表示实时供给不足，先检查启动日志是否成功请求低延迟、遥控器是否刚重连及系统是否升级；不要靠增加音量掩盖缺帧。私有接口不可用时应用会警告，当前没有已验收的通用替代路径。新的固定增益不会像旧AGC那样跨会话不断放大背景噪声；靠近麦克风、降低环境噪声仍然有帮助。重复字也可能来自外部识别器或热键配置，修复音频并不等于所有识别问题均已解决。
