# 普通按键断线恢复

症状：蓝牙断开后语音重新连上，普通按键却无响应；返回键配置仍为 Backspace。PacketLogger 在启动时输出设备 UUID 与连接 handle 的快照，持续运行时的重连并不保证重复输出该快照。解码器正确拒绝未知连接，导致旧会话永久失去普通按键。

修改：未绑定时最多每 5 秒重启已验证的私有 PacketLogger 子进程，重新读取选定 UUID 的快照。不根据设备名猜测身份，不重新申请管理员权限，不重启语音连接。以代次标识隔离旧子进程的输出和退出回调。停止、父进程退出及错误仍使用同一设置恢复路径。界面断线时清除就绪状态；绑定选定设备后才显示就绪。

验证：215 项检查全部通过，应用与助手构建和签名验证通过。本地安装后自动绑定成功；用户单按返回键，测试文本 ABC123 精确变为 ABC12。物理断线后的自动恢复仍需后续实机覆盖；本次回归覆盖刷新节流、绑定时不中断，以及旧连接拒收、指定 UUID 重绑定。
