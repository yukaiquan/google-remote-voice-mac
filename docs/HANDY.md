# 搭配 Handy 使用遥控器语音输入

[← 返回项目首页](../README.md)

按住 Google 遥控器语音键，说话，松开后由 Handy 转成文字并粘贴到光标所在位置。本项目负责音频与按键，Handy 负责识别。

**[Handy 官网与下载](https://handy.computer/) · [GitHub 开源项目](https://github.com/cjpais/Handy) · [最新发行版本](https://github.com/cjpais/Handy/releases/latest)**

## 1. 准备应用

- 完成[本项目安装](../README.md#快速开始)，确认遥控器已连接。
- 确认已安装 [BlackHole 2ch](https://github.com/ExistentialAudio/BlackHole)。首次安装后若看不到设备，按驱动说明重启。
- 从上面的官方入口下载适合自己 Mac 的 Handy，打开后按提示完成麦克风、辅助功能等权限设置。
- 在 Handy 中下载一个支持目标语言的本地识别模型。首次下载需要联网；使用本地模型识别与可选的云端后处理是不同步骤。

本项目的本地配套验证使用过 **Handy 0.8.3 + SenseVoice + BlackHole 2ch**。这是一组实测配置，不表示必须安装旧版本；其他版本请按下面的输入源、触发键和录音方式逐项核对，界面名称可能不同。

## 2. 对齐三个关键设置

| 设置 | Handy | Google Remote Voice |
| --- | --- | --- |
| 输入源 | **BlackHole 2ch** | 将遥控器解码音频输出到 BlackHole |
| 录音方式 | **Push to Talk / 按住说话** | 语音键保持“同时开启麦克风” |
| 触发快捷键 | 例如 **右 Command** | 语音键默认右 Command，或录制成同一快捷键 |

明确选中 **BlackHole 2ch**，不要误选 Mac 内置麦克风、摄像头或手机麦克风。快捷键能触发录音，不代表 Handy 收到的一定是遥控器音频。

若右 Command 与你的其他软件冲突，可以在两边统一换成别的组合键：本应用点语音键的“录制”，在 **Mac 键盘**上输入组合键，再到 Handy 录制同一个组合键。不要在“录制”时按遥控器来学习按键。

## 3. 试说一句

1. 在文本编辑或其他应用中创建空白文本框，确认光标在框内。
2. 按住遥控器语音键，只说一次“今天我要打开 Codex 开始工作”。
3. 松开语音键，等待 Handy 处理并交付文字。
4. 确认只出现一份文字，再开始日常输入。

默认麦克风增益为 **18 dB**。声音小可在本应用的“麦克风音量”里调节；调到最大也会放大环境噪声，先靠近遥控器麦克风试说。

## 连续输入

保持按住语音键，松开后再转写；中途正常停顿不必松键。一次本机测试持续约 **95 秒**并交付一条 Handy 结果，结束伴随蓝牙断开，不能据此保证固定或无限录音时长。若遥控器断线，或连续 3 秒没有音频数据，当前会话会停止，需要重新按住。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 有录音提示，却识别不到自己说的话 | Handy 输入设备是否明确选中 **BlackHole 2ch** |
| 松开后不出字 | 模型是否下载完成、两边快捷键是否一致、Handy 是否为按住说话、光标是否在可编辑区域 |
| 一句话出现两份或多出文字 | 是否同时开启 macOS“语音控制”、系统听写或其他相同热键的录音工具；逐个暂停后复测 |
| 声音小 | 本应用麦克风音量先用推荐 18 dB，并靠近麦克风 |
| 杂音、破音或断续 | 查看本应用语音接收统计；本样机正常长语音约 50 包/秒，调大增益不能修复丢包 |
| 普通键接收未开启 | 检查 PacketLogger、权限和接收状态；应用默认自动启动接收，系统仍可能要求管理员授权 |

更多问题见[故障排查](TROUBLESHOOTING.md)。

## 数据与项目关系

Handy 是独立维护的开源项目。本地语音识别可以离线运行；若另外开启云端模型或后处理，请单独核对对应服务的数据设置。本仓库不捆绑 Handy、识别模型或 Apple 工具，也不代表这些项目的官方合作或认证。
